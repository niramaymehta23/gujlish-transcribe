# Clip rules

Copy this file to `clip_rules.md` (kept out of Git) and replace the placeholders with your channel's real rules.
`python clips.py` sends the whole file to the model as the rules every clip must meet, so write it the way you would
brief a person cutting clips for you. Length (0:30 to 3:00) is enforced by the program; you don't need to repeat it.
